# TripSplit

Google Stitch에서 만든 여행 경비 정산 디자인을 바탕으로 구현한 브라우저용 여행 가계부입니다. HTML, CSS, 순수 JavaScript를 사용하며 프레임워크와 설치할 패키지가 없습니다.

## 실행

Node.js 20 이상을 설치한 후 이 프로젝트 폴더에서 실행하세요.

```powershell
npm.cmd start
```

브라우저에서 **http://localhost:3000** 을 여세요. 종료는 터미널에서 `Ctrl+C`입니다. `node server.js`로 실행해도 같습니다. HTML 파일을 직접 더블클릭하면 JavaScript 모듈이 제한될 수 있으므로 위 명령어를 사용하세요. `server.js`는 정적 파일만 제공하는 로컬 미리보기 도구입니다.

## 사용 방법

1. **새 여행 만들기**에서 이름, 시작일·종료일, 참여자 이름을 입력합니다. 참여자는 자유롭게 추가·삭제할 수 있습니다. 동명이인은 별명으로 구분합니다.
2. 여행 목록에서 여행을 선택하면 해당 여행 대시보드가 열립니다.
3. **지출 추가**에서 여행 기간 내 날짜, 항목, 원화 금액, 결제자와 부담자를 입력합니다. 처음에는 전원이 선택됩니다.
4. 금액이나 부담자 변경 시 각자의 부담액이 즉시 표시됩니다. 대시보드에서 저장된 지출을 수정하거나 확인 후 삭제할 수 있습니다.
5. **정산 결과 보기**에서 결제액, 부담액, 잔액, 참여자 간 송금 안내를 확인합니다. 결과를 인쇄하거나 브라우저 인쇄 대화상자에서 PDF로 저장할 수 있습니다.

## 프로젝트 구조

```text
index.html             실행 진입점, 원본 Stitch Tailwind 설정 및 랜딩 템플릿
styles.css             원본 디자인 색상에 맞춘 공통 UI와 모바일 스타일
js/app.js              화면 렌더링, 폼, 이동, 지출 관리
js/calculations.js     정수 분할, 참여자별 집계, 송금 계산
js/storage.js          localStorage 저장·조회와 데이터 검증
server.js              외부 패키지 없는 정적 파일 미리보기 서버
tests/tripsplit.test.js 계산과 저장 로직 자동 테스트
tests/browser.mjs      테스트 전용 Edge 화면 검증 도구
scripts/prepare-design.py  원본 랜딩 HTML을 index.html로 가져오는 보조 도구
stitch_tripsplit_travel_expense_tracker/  수정하지 않은 Stitch 원본
```

원본 폴더에는 `tripsplit_1`(랜딩), `_`(대시보드), `tripsplit_2`(지출 등록), `tripsplit_3`(정산)의 `code.html`·`screen.png`와 `tripsplit/DESIGN.md`가 있습니다. 원본은 독립 HTML 화면이며, 작동하는 앱은 루트 `index.html`에서 시작합니다. 랜딩의 HTML·Tailwind 테마를 재사용하고 공통 컴포넌트를 원본 팔레트·카드·배너 구성에 맞춰 구현했습니다.

## 계산과 데이터

- 원화는 안전한 정수 금액만 허용합니다. 10,000원을 3명이 나누면 등록 순서대로 3,334원 / 3,333원 / 3,333원입니다.
- 각 지출에 선택된 참여자만 부담합니다. 결제자는 부담자에서 제외할 수도 있습니다.
- 개인별 잔액은 `결제액 - 부담액`입니다. 양수는 받을 돈, 음수는 보낼 돈입니다.
- 송금 안내는 받을 사람과 보낼 사람을 순서대로 연결해 모든 잔액을 0원으로 만듭니다. 모든 경우에서 송금 횟수가 수학적으로 최소라는 보장은 하지 않습니다.
- 저장 키는 `tripsplit.v1`이고 구조는 `{ version: 1, trips: [...] }`입니다. 여행·참여자·지출은 고유 ID로 구분합니다.
- 새로고침 후에도 유지되지만 동일 브라우저·프로필·주소에서만 볼 수 있습니다. `localhost`와 `127.0.0.1`도 별도 저장소입니다. 브라우저 데이터 삭제·시크릿 모드 종료 시 기록이 사라질 수 있습니다.
- 저장 공간 부족과 읽을 수 없는 데이터에는 오류를 표시합니다. 손상된 데이터를 자동 초기화하거나 덮어쓰지 않습니다.
- 원본 Tailwind CDN 및 Google Fonts를 유지하므로 원본과 같은 랜딩 디자인·폰트에는 인터넷 연결이 필요합니다. 공통 앱 스타일은 로컬 CSS입니다.

## 테스트

```powershell
npm.cmd test
```

분할 나머지, 사용자 요청의 식사/KTX 예제, 수정·삭제, 여행 분리, 저장 후 복원, 입력 검증, 저장 실패, 손상 데이터 보존과 200가지 정수 조합의 금액 보존을 검사합니다.

`tests/browser.mjs`는 별도의 테스트용 Edge 프로필이 포트 9222에서 개발자 프로토콜을 제공하고 로컬 서버가 실행 중일 때 `node tests/browser.mjs`로 실행합니다. 테스트 프로필의 TripSplit 데이터를 초기화하므로 평소 사용하는 브라우저 프로필에 연결하지 마세요. 실제 화면에서 여행 생성, 참여자 추가·삭제, 지출 CRUD, 일부 부담, 정산, 새로고침, 여행 분리, 뒤로 가기와 모바일 가로 넘침을 검사합니다.

## 이번 범위에서 제외한 기능과 이후 DB 전환

회원가입·로그인, 서버 API, 데이터베이스, 외부 API, 실시간 공동 편집, 실제 송금은 구현하지 않았습니다. 여행 생성 후 참여자 편집은 제공하지 않으며 생성 화면에서 추가·삭제할 수 있습니다.

Neon으로 전환할 때는 여행·참여자·지출·지출별 부담자 테이블과 서버 API를 만든 뒤 `js/storage.js`의 저장·조회 인터페이스를 API 호출로 교체하고 화면에서 비동기 응답을 처리하면 됩니다. DB 접속 문자열은 브라우저 코드에 넣지 않고 서버 환경 변수로 관리해야 합니다. 계산 모듈은 그대로 재사용하고, 서버에서도 입력 검증·정수 범위 검사를 수행하세요. 필요하다면 기존 localStorage 데이터를 가져오는 마이그레이션과 사용자별 접근 권한을 별도 설계합니다.
